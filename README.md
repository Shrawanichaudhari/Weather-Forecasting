# Weather-Forecasting
This project is a Weather Forecasting Web Application that provides real-time weather data for any location worldwide. It leverages public weather APIs to fetch and display current weather conditions, including temperature, humidity, wind speed, weather description, and more. The app features a clean, responsive UI for a seamless user experience across devices.

🔧 Features
🌍 Search weather by city name

📍 Geolocation-based weather updates

🌡️ Displays temperature, humidity, wind speed, pressure

🧭 Shows weather description and icon

📅 Real-time date and time display

🎨 User-friendly and responsive interface

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

API: OpenWeatherMap API (or any other)

Tools: VS Code, Git, GitHub
